# Control - Benchmarking & Testing Module

This folder contains benchmarking and testing utilities for the control module.

## Directory Structure
* **[tests/](file://${ROAR_WS}/src/navstack/control/benchmarking_and_testing/tests)**: Unit and integration test cases for rover controllers (e.g. MPPI).
* **[mocks/](file://${ROAR_WS}/src/navstack/control/benchmarking_and_testing/mocks)**: Mock actuator hardware feedback, state estimation inputs, and trajectories.
* **[results/](file://${ROAR_WS}/src/navstack/control/benchmarking_and_testing/results)**: Controller command execution latency logs, target tracking errors, and benchmark runs.
