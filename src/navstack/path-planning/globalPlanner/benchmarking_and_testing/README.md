# Global Planner - Benchmarking & Testing Module

This folder contains benchmarking and testing utilities for the global path planning module.

## Directory Structure
* **[tests/](file://${ROAR_WS}/src/navstack/path-planning/globalPlanner/benchmarking_and_testing/tests)**: Unit and integration test cases for global path planning algorithms (e.g. D*).
* **[mocks/](file://${ROAR_WS}/src/navstack/path-planning/globalPlanner/benchmarking_and_testing/mocks)**: Mock maps, occupancy grids, and route goals.
* **[results/](file://${ROAR_WS}/src/navstack/path-planning/globalPlanner/benchmarking_and_testing/results)**: Path optimality records, search computation times, and benchmark reports.
